আচার ঘর — Professional Website
================================
index.html = মূল ওয়েবসাইট
style.css  = ডিজাইন
script.js  = Product filter + Cart + basic interactions

নিজের ব্যবসার তথ্য বদলাতে:
- index.html-এর ফোন, ঠিকানা, ইমেইল বদলান
- script.js-এর products তালিকায় পণ্যের নাম/দাম/বর্ণনা বদলান
- নিজের ছবি বসাতে style.css-এর hero background URL বদলান

গুরুত্বপূর্ণ:
এই ডেমোতে checkout/payment backend নেই। বাস্তবে চালু করার আগে bKash/Nagad/SSLCommerz বা COD order backend যুক্ত করতে হবে।
